# Mapa de contexto para tareas de ingenieria

Este documento responde una sola pregunta: **para esta tarea, que fuentes autoritativas hay que leer antes de trabajar?** No reemplaza esas fuentes ni `EGRESADO-MASTER-SPEC.md`.

Lee primero [la autoridad documental](../README.md#autoridad-documental). Despues usa la fila mas estrecha que cubra la tarea y suma documentos solo cuando el cambio cruce otra frontera. Revisa tambien [las preguntas abiertas](../07-reference/open-questions.md) si la tarea toca una decision aun no cerrada.

## Reglas de uso

- No uses el master consolidado como sustituto de las fuentes individuales.
- Una version de libreria instalada, su documentacion incluida y sus tipos prevalecen sobre memoria del modelo para APIs de implementacion.
- Una tarea que cruza filas debe leer la union minima de fuentes, no todo `docs/`.
- Si la evidencia no cierra una decision, enlaza la pregunta abierta en el plan y limita el cambio a lo que ya esta decidido.
